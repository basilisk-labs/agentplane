# Release Notes — v0.7.6

## Summary

- AgentPlane 0.7.6 removes the first-task lifecycle failures reported against 0.7.5: plans remain lossless and language-neutral, envelopes recover safely, and lifecycle state no longer becomes unusable after a bounded artifact is written.
- Execution strategy is now agent-selected from a structured risk and effect declaration, while AgentPlane deterministically enforces the canonical lifecycle, safety, verification, and publication invariants.
- Verification is substantially faster and more selective: one monotonic Verification Contract drives local, PR, evaluator, recovery, and release checks, with conservative full-regression fallback for central or unknown changes.
- Branch-PR housekeeping, integration queues, worktree cleanup, hosted closeout, CI routing, and exact-SHA release evidence are more deterministic and auditable.

## Added

- Added an installed-package mixed-scope lifecycle E2E that exercises the same first-project task flow users run outside the AgentPlane source checkout.
- Added risk-adaptive execution declarations so the agent can choose `direct` or `branch_pr` semantically without keyword classification or user-facing strictness profiles.
- Added primary, digest-bound incident and qualification evidence so release blockers can be archived only after their fixes, hosted checks, and remaining operator state are independently reviewable.

## Improved

- Made episode plans lossless, language-neutral, and large enough for real product work without forcing a specific language.
- Reduced verification amplification through deterministic change selection, reusable immutable evidence, bounded parallel groups, and exact-SHA lifecycle evidence reuse.
- Improved CI routing so irrelevant Windows, package-runtime, documentation, security, and real-E2E lanes are skipped while required gates remain fail-closed.
- Improved queue recovery and worktree cleanup so merged tasks can be reconciled and removed without accumulating stale task folders or branches.

## Fixed

- Fixed used-envelope, stale-exchange, fingerprint, evaluator authority, and lifecycle-tail failures exposed by the 0.7.5 first-task log and the installed-package reproduction.
- Fixed declared-check validation and supervised execution using different command grammars.
- Fixed RF-04 provider replay dependency discovery in shared worktrees.
- Fixed stale verification and evaluator identity rotation across lifecycle-only commits without allowing semantic changes to reuse unrelated evidence.
- Fixed the compatibility release gate so future patch candidates are validated from their exact manifest surface instead of a hard-coded prior version, while provenance, digests, and allowed paths remain fail-closed.

## Upgrade Notes

- No user action is required. Legacy execution-profile values remain readable but no longer define weaker or stronger AgentPlane process variants.
- Existing projects keep their project-specific workflow and integration settings; task execution strategy is derived per task from the agent's structured declaration and deterministic repository policy.

## Verification

- The release candidate is qualified with the full 20-scenario gate, the pinned Codex 0.146.0-alpha.3.1 provider matrix, release parity, the canonical prepublish suite, exact-SHA hosted checks, and post-publication npm/GitHub readback.
