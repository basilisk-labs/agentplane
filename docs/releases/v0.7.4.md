# Release Notes - v0.7.4

## Summary

- AgentPlane 0.7.4 completes the 0.7 refactor with a CLI-owned execution envelope that prepares compact typed context, preserves exact semantic effects, and keeps task, release, and provider state recoverable.
- This patch consolidates the post-release audit into one qualified update instead of publishing a sequence of speculative fixes.

## Added

- Added an exact-result recovery contract for late PLANNER responses so only the plan that is currently persisted can complete an uncertain operation.
- Added regression coverage for stale planning results that preserves the independently revised plan and leaves the supervisor journal retry-safe.
- Added compact, immutable qualification evidence for the exact release subject, including provider provenance, effectiveness, matched latency, and supervisor latency.
- Added structured verification records that bind commands, results, evidence, and scope to the reviewed implementation and archived evidence set.

## Improved

- Improved release recovery so the current package version and tag determine the active target instead of a stale local release-plan SHA.
- Improved release next-action diagnostics to separate current-target evidence from obsolete hosted workflow state.
- Improved release evidence collection to resolve the successful exact-SHA publish run and reuse its canonical publication result idempotently.
- Improved supervisor recovery so a semantic side effect is reconciled exactly once across process interruption and uncertain provider completion.
- Improved the Codex and Hermes supervisor frontends to share the same execution-episode state, usage accounting, and stop semantics.
- Improved task-owned artifact commits so recovery metadata remains aligned with the repository commit policy.
- Improved provider conflict and rework coverage with a realistic aggregate time budget while preserving strict per-scenario failure reporting.
- Improved verification freshness so evidence-only commits remain distinguishable from the implementation SHA reviewed by the evaluator.

## Fixed

- Fixed stale release plans mixing an old release SHA with diagnostics for the current version and tag.
- Fixed failed or incomplete postpublish audits being stored in a shape that could appear reusable as successful evidence.
- Fixed late PLANNER results being accepted merely because any plan was awaiting approval, even when the returned plan differed.
- Fixed supervisor recovery modules exceeding repository size and lint constraints after the recovery paths were consolidated.
- Fixed formatting drift in the provider conflict-rework matrix that blocked the repository contract gate.
- Fixed quality handoff records that previously lacked machine-parseable command, result, evidence, and scope fields.

## Upgrade Notes

- No migration is required; upgrade with `npm install --global agentplane@0.7.4`. Existing 0.6.x and 0.7.x repositories remain supported by the qualified upgrade fixtures.

## Verification

- The full release qualification completed 50 of 50 semantic runs and 55 of 55 provider episodes without retry, with zero blocking failures.
- Compared with the frozen baseline, measured provider tokens fell from 9,186,747 to 6,263,560, verified successes rose from 8 to 20, scope violations fell from 17 to 5, and golden mismatches fell from 33 to 10.
- The deterministic prepublish suite, package and upgrade matrices, matched CLI latency, both supervisor latency frontends, critical CLI, Windows, CodeQL, documentation, static analysis, unit tests, and protected-main checks passed before release preparation.
