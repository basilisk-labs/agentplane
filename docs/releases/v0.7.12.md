# Release Notes - v0.7.12

## Summary

- Reuse qualified caller-supplied plans through `task create --plan-file` while preserving plan approval, independent evaluation, immutable provenance, and fail-closed policy checks.

- M04 efficiency is NOT ESTABLISHED. Controlled transport tests do not certify live-provider containment; this release does not claim token or cost savings.

## Upgrade Notes

- Upgrade `@agentplaneorg/core`, `@agentplaneorg/recipes`, and `agentplane` together to `0.7.12`; internal package pins and runtime version metadata are aligned.
- Supplied plans may use compact v2 or full v1 input. A plan file is not approval. Mandatory planning policy and missing capability evidence still prevent reuse.
- Preserve `plan_inputs` and `plan_input_digest` when moving task records between installations. Older writers must not mutate records whose immutable supplied-plan provenance they cannot preserve.
- Repository-policy approval is limited to qualified bounded repository-only work when policy permits it. External effects and uncertain work still require explicit user authority.
- Legacy schema-version-1 supervisor budget fields remain readable for compatibility, but they are not active spend limits. New execution does not create `budget_exhausted` stops; `task supervisor budget-epoch` is retired.
- `cleanup inspect` is read-only. Its output does not authorize deletion of dirty or active worktrees, or unrelated repositories.
- Independent recipes checkouts can be selected by the documented source option or environment setting. Shallow read-only inventory is a fallback; signed runtime catalog verification is unchanged.
- Roadmap documentation for 0.7.13 and 0.7.14 is planning material, not a claim that those future capabilities ship in 0.7.12.
