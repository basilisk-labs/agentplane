# Release Notes - v0.7.2

## Summary

- AgentPlane 0.7.2 repairs the post-publish evidence handoff so a successful release is recorded against the correct canonical task even when several completed release tasks mention the same version.

## Added

- Added regression coverage for rebase-merged release heads whose final commit changes task-scoped PR artifacts rather than the task README itself.

## Improved

- Release-task attribution now combines the exact release commit with version-qualified task metadata before falling back to repository-wide version matching.

## Fixed

- Fixed the v0.7.1 failure mode where hosted publication completed successfully but evidence recording stopped as ambiguous because qualification, audit, and publish tasks all referenced v0.7.1.

## Upgrade Notes

- No migration is required; upgrade with `npm install --global agentplane@0.7.2` and continue using the existing 0.7 workflow.

## Verification

- The targeted evidence suite, real v0.7.1 publish-result replay, repository contract gate, release prepublish gate, protected-main checks, exact-SHA publication, clean-install smoke, and postpublish audit must all pass.
