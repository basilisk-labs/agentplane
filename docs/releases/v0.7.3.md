# Release Notes - v0.7.3

## Summary

- AgentPlane 0.7.3 closes the hosted release-evidence loop without operator repair and keeps completed release tasks terminal after publication evidence lands.

## Added

- Added exact-SHA Core CI verification and a GitHub Actions-owned required check for release-evidence pull requests.
- Added regressions that preserve canonical task-verification provenance while hosted publication evidence is appended.

## Improved

- The publish workflow now waits for the evidence commit to pass Core CI and for its pull request to merge before the release workflow succeeds.
- Release-evidence failures are fail-closed instead of being hidden behind best-effort continuation.

## Fixed

- Fixed evidence pull requests created by GitHub Actions remaining blocked because workflow-dispatch checks were not associated with the pull request.
- Fixed hosted publication evidence overwriting the accepted TESTER verification record and sending an already completed task back to `verification_required`.

## Upgrade Notes

- No migration is required; upgrade with `npm install --global agentplane@0.7.3` and continue using the existing 0.7 workflow.

## Verification

- The release-evidence selection and preservation suites, publish-workflow contract, repository contract gate, release prepublish gate, protected-main checks, exact-SHA publication, clean-install smoke, postpublish audit, autonomous evidence merge, and terminal task route must all pass.
