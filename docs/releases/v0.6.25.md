# Release Notes - v0.6.25

## Summary

- AgentPlane now gives verified direct-workflow tasks a concrete, executable closeout command instead of presenting a placeholder-based command that it simultaneously rejects as unsafe.
- AgentPlane now recognizes an existing local task worktree after `work start` and routes the agent forward to PR creation instead of repeatedly recommending another worktree start.
- Both routing repairs include focused regression coverage and passed the full local and hosted verification suites.

## Added

- Added focused direct-closeout regression coverage proving that a verified task receives concrete `exactArgv`, `safe_to_mutate=true`, and `canExecuteNow=true` guidance. (aef3a06)
- Added a work-start routing regression proving that exactly one matching local task branch is discovered and routed to `pr open` when hosted PR metadata does not exist yet. (c3d51c3)

## Improved

- Recorded the direct-closeout verification evidence separately so the executable routing contract remains auditable through task closure. (b9a1ba4)
- Preserved the combined closeout and post-work-start routing implementation, test evidence, and task metadata through the maintenance integration path. (7781617)
- Corrected the task's integration verification commands to use the matching Vitest projects, ensuring the route oracle can rerun the exact focused suites successfully. (1fb4ba8)
- Integrated the verified routing changes into the `v0.6.24` maintenance branch with the hosted PR evidence and closeout artifacts intact. (1147dbf)
- Initialized the isolated `v0.6.25` release task and candidate branch so publication can proceed from the maintenance line without merging into `main`. (1ad3008)

## Fixed

- Fixed the direct-workflow closeout route so a verified persistent-carrier task receives a concrete `task complete` command rather than an unsafe placeholder template.
- Fixed local branch inference after `work start`, preventing AgentPlane from looping back to the same worktree creation command when the task branch already exists.
- Kept mutation authority aligned with the emitted command: actionable closeout and PR routes are now marked executable only when their arguments are concrete.

## Upgrade Notes

- No breaking changes are introduced by this patch release.
- The published package set moves from `0.6.24` to `0.6.25`.
- No migration or configuration change is required.
- Publication is intentionally based on `codex/fix-v0.6.24-closeout-route`; this maintenance release is not merged into `main`.
