# First local run

## What is the first success path?

The first success path creates one task, previews its route without invoking a model provider, and
shows the task record that Agentplane keeps in the repository. Run it from a repository where
`agentplane init` has already completed (see [Quickstart](quickstart)).

```bash
agentplane task create "Inspect Agentplane artifacts and summarize what was created" --json
agentplane task active
agentplane task run <task-id> --dry-run --json
agentplane task show <task-id>
```

- `task create` prints the new `task_id`.
- `task active` lists ready and in-progress tasks with their next route step.
- `task run --dry-run --json` returns `execution_preview`: route, bounded context, approvals,
  checks, and budgets. It does not start a runner.
- `task show` prints the task record.

To hand the task to an external coding agent, request one bounded action:

```bash
agentplane task advance <task-id> --agent-json
```

## Where are the artifacts?

```text
.agentplane/tasks/<task-id>/README.md   # task record: intent, plan, verification, findings
.agentplane/tasks/<task-id>/            # supervision, quality, and PR evidence as the task advances
.agentplane/WORKFLOW.md                 # workflow contract used to route the task
```

See [What files does Agentplane write?](files-written) for the full map.

If a command is not available in your installed version, run `agentplane quickstart` and
`agentplane help` to inspect the supported route for that installation.
