## Inference and confirmation

Primary inference resamples whole task clusters within each fixed stratum, carrying all repetitions and arms together. The empirical stratum allocation is fixed by registration; no post-hoc reweighting is allowed. Two treatment-versus-baseline comparisons each have token, quality and active-time bounds: six one-sided bounds share a Bonferroni familywise alpha of 0.05. Each bootstrap sample includes the exact one-time external setup total once per arm; it does not resample the descriptive assignment allocation shares. The token and time implementation uses a deterministic matched cluster percentile bootstrap with 10,000 resamples. Quality uncertainty instead uses a conservative weighted bounded-task-cluster Hoeffding lower bound: observed difference minus the square root of `2 × log(6 / alpha) × sum(task_weight²)`, bounded below by -1. Registered task clusters must be independent for that population bound; repetitions within a task are not treated as independent. This avoids a zero-width population interval when every observed pair succeeds. Bootstrap coverage is approximate; independent review must assess finite-sample adequacy before a confirmatory claim.

A resample with no successes, a zero baseline denominator or incomplete usage/time is retained as nonfinite and prevents a finite bound. At least two independent task clusters per stratum are needed even to compute these bounds. This is an algorithmic minimum, not a power calculation. The pilot has only one task per stratum; its repetitions do not create independent clusters and cannot establish confirmation savings. Matched successful pairs are secondary only. Primary totals retain failures and unknowns.

The intended quality scope is the fixed registered benchmark. Its quality gate requires independently verified, paired observed nonregression for every assigned comparison, while reporting uncertainty separately. It makes no universal or population quality-equivalence claim. A separately registered population claim would instead require its conservative quality lower bound above a prospectively ratified noninferiority margin. All required gates form an intersection: the registered quality rule, a token-ratio upper bound below the prospectively ratified savings margin, a time-ratio upper bound below its ratified margin, and no observed safety/oracle/authority violation. Missing evidence defeats the gate. Zero observed violations is not proof of universal safety. A token gain with worse quality or unacceptable time is `MIXED`; supported harm is adverse; insufficient evidence is `NOT_ESTABLISHED`.

After the pilot closes, register a separate fixed confirmation using independent new tasks from the prespecified five-stratum population. Do not select tasks for favorable observed treatment results or reuse pilot outcomes in inference. Freeze sample size, repetitions, margins, reuse horizon, setup attribution, power/sensitivity review, seed, exact analysis code and all source/runtime/oracle pins before the first confirmation turn. These confirmation quantities remain unresolved until pilot evidence and independent review support them. If resources cannot support adequate precision, report the limitation rather than weaken the criterion. Product or oracle changes require a new prospective registration; preserve the abandoned study.
